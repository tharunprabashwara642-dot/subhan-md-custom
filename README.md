## ⚙️ Configuration

Configured via environment variables:

- `SESSION_ID`
- `PAIRING_NUMBER`
- `BOT_NAME` (Default: `𝐓𝐡𝐚𝐫𝐮𝐧-𝐌𝐃`)
- `BOT_OWNER` (Default: `𝐓𝐡𝐚𝐫𝐮𝐧 𝐏𝐫𝐚𝐛𝐡𝐚𝐬𝐡𝐰𝐚𝐫𝐚`)
- `PREFIXES`
